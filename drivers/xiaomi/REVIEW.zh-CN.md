# 小米录音驱动人工审阅清单

这是 OpenList 内置驱动，当前分支用于本地试用和公开审阅，尚未向官方提交 PR。

此实现包含 Codex 辅助生成的代码、测试、协议分析和文档。用户已实际确认网页播放、下载正常；下面的代码审阅尚未完成，不能把功能试用等同于全面代码审阅。

## 逐轮审阅

每轮先解释用户可见行为，再查看对应实现和测试，讨论取舍并记录问题；确认理解和接受后再勾选。

- [ ] 配置和凭据保存：查看 `meta.go`、`driver.go` 和 `client.go` 的初始化、Cookie 保存与账号切换。密码哈希等同登录凭据，需要保护 OpenList 数据库。
- [ ] 登录和令牌恢复：查看 `client.go` 的 `entry`、`follow`、`refresh`、`login`、`api`，确认签名回调、设备信息保留、密码回退间隔和一次重试限制。
- [ ] 短信验证：查看 `verify` 和相关测试，确认仅用户主动发送短信、验证码用后清除、记住设备；真实新短信挑战尚待验证。
- [ ] 录音列表和下载：查看 `driver.go`，确认分页、唯一文件名、只读能力、下载主机限制及分段下载处理。
- [ ] 测试、许可和提交说明：检查测试能否复现、未验证限制、上游全仓测试已有失败以及 AI 使用披露。

## 已完成的验证

- 用户确认网页播放、下载成功。
- 实际账号列出 3426 条录音；样本大小、SHA1 和分段下载内容一致。
- 独立 fnOS 测试实例验证存储编辑、停用/启用、OpenList 进程重启后登录状态保留。
- 将短期服务凭据设为已过期后，自动使用长期登录凭据恢复。
- 同时将服务凭据和 passToken 设为已过期、保留设备信任后，自动账号密码登录成功。两种情况下列表、下载与分段内容均通过。
- HTTP 401、云端错误码与持续认证失败的模拟测试确认只刷新重试一次。
- 驱动及相关框架测试、驱动静态检查通过；全仓测试有 15 个包失败，与同一提交的未修改上游基线一致。

主动模拟过期不能证明数月连续运行稳定性。真实新短信挑战、全新不受信任设备、第二个账号、图片验证码、其他验证方式和整机 NAS 重启仍待验证。

## 公开内容边界

此目录仅包含代码、测试和说明。真实 HAR、账号凭据、Cookie、签名下载链接、私人录音及其元数据不应提交。未来提交官方 PR 时，按官方模板如实填写测试、AI 使用和人工审阅情况。

## 非永久删除补充审阅

- [ ] 核对 `Remove`：仅有效录音 ID，固定 `permanent=false`，认证后提交一次，失败不自动重试，本地备份不删除。
- [ ] 用自行选定的可丢弃录音做真实删除验证；当前只有抓包协议及模拟接口测试，未由自动测试删除真实录音。

永久删除、手机同步删除影响及云端恢复保留期限尚未验证。
